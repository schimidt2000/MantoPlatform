# Contratos — Feature 351

Dinheiro sempre string decimal com 2 casas ("123.45"); datas `AAAA-MM-DD`; carimbos ISO no horário de SP. Campo novo
é opcional no React (`docs/00` §6 item 21). Erro no envelope de `json_error`.

## `GET /api/conversas/funil` (existe) — COMERCIAL, SUPERADMIN

`dividir` aceita também `frente | anuncio | peca | conceito`. Nenhuma chave de dinheiro no payload, para ninguém.

## `GET /api/marketing/frentes` / `PATCH` (existem)

Leitura: cada frente ganha `meta_vendas_mes` (int|null) e `verba_mes` (string|null).
Escrita (só Superadmin real): corpo aceita `metas: {slug: int|null}` e `verbas: {slug: "123.45"|null}` além de
`tetos`, `resp_foto_id`, `resp_video_id`. 400 com `fields["metas.<slug>"]`/`fields["verbas.<slug>"]`.

## `PATCH /api/marketing/calendario` (novo) — só SUPERADMIN real (403 para os outros)

Corpo: `{"frente": "festas", "meses": [{"mes": 3, "meta_vendas": 50, "verba": "3000.00", "foco": "…"}]}` — só os meses
enviados mudam; `null` limpa. 400 em frente/mês/valor inválido (`fields["meses.<i>.verba"]`). Resposta = o GET.

## `GET /api/marketing/propostas` (existe)

Cada item ganha `frente`, `frente_nome`, `valor_antes_num`, `valor_depois_num`, `impacto_mensal`, `teto`, `verba_mes`.
A resposta ganha `impacto_aprovado_mes` (soma das aprovadas e executadas decididas no mês corrente, SP).

## `GET /api/marketing/diario` / `POST` (existem)

`POST` aceita, opcionais: `alvo_platform`, `alvo_tipo`, `alvo_id`, `alvo_nome`, `metrica`, `mudou_em`, `janela_dias`,
`linha_base`, `controle_tipo`, `controle_id`, `controle_nome`. Cada item ganha:


## `GET /api/marketing/posts` (existe) e `POST|PATCH /api/marketing/posts[/<id>]`

Card ganha `conceito`; `anuncios[]` ganha `no_ar` (bool|null) e `ultimo_gasto_em` (data|null); `resultado` ganha
`conversas_reais`, `orcamentos`, `eventos`, `vendas`, `faturamento`, `anuncios_no_ar`, `ultima_leitura`.
Escrita aceita `conceito` (≤ 120).

## `GET /api/marketing/temas-licenca` (existe)

Query ganha `pagina` (1…). Resposta ganha `total`, `pagina`, `paginas`, `por_pagina` (50).

## Agente (rotas sem mudança)

- `GET …/comando`: ganha `calendario` (frentes × meses) e `metas_do_mes` (por frente: meta, verba, foco do mês).
- `POST …/pedidos`: item aceita `conceito`.
- `POST …/propostas`: aceita `frente`, `valor_antes_num`, `valor_depois_num`.
- Execução de proposta: a entrada do diário herda alvo e métrica.
