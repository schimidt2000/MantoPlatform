# Contrato da API — Feature 345

Envelope de erro de sempre (`json_error`): `{"error": {"message", "fields"?, "codigo"?}}`. Dinheiro em string decimal
("300.00"). Datas `AAAA-MM-DD`.

## Tela (sessão; gate por função no início da view)

| Método e rota | Papéis | Corpo / resposta |
|---|---|---|
| `GET /api/marketing/desempenho` | MARKETING, SUPERADMIN | ganha `frentes` (abaixo), `sem_frente[]`, `plataformas[]` |
| `PATCH /api/marketing/campanhas/frente` | MARKETING, SUPERADMIN | `{platform, campaign_id, frente \| null}` → `{ok}`; `null` desfaz a correção |
| `GET /api/marketing/frentes` | MARKETING, SUPERADMIN | `{frentes: [{slug, nome, teto, teto_padrao, base_teto, teto_editado}], responsaveis: {foto, video}, pode_editar}` |
| `PATCH /api/marketing/frentes` | SUPERADMIN | `{tetos?: {slug: "575.00" \| null}, resp_foto_id?, resp_video_id?}` |
| `GET /api/marketing/temas-licenca` | MARKETING, SUPERADMIN | `?q&origem&liberado&sugestao=1` → `{items: [{id, name, cover_url, licenca_origem, liberado_anuncio, licenca_sugestao, licenca_sugestao_motivo, licenca_por, licenca_em}], contagem, pode_liberar_licenciado}` |

## Agente (`/api/marketing-agent/<token>/…`, token errado = 404, molde da 256)

| Método e rota | Corpo | Resposta |
|---|---|---|
| `GET …/comando?start&end` | — | `{frentes, sem_frente, plataformas, temas_liberados[], temas_sem_classificacao: n, cards_prontos_sem_anuncio[], propostas_a_executar[], diario_a_reavaliar[], responsaveis}` |
| `POST …/anuncios` | `{items: [{platform, ad_id, ad_name, adset_id, campaign_id, campaign_name, metric_date, spend, currency?, impressions?, reach?, clicks?, conversations?, leads?, results?}]}` | `{upserted}` (idempotente) |
